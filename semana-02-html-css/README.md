##  ✅ O que foi feito 
- Foram criados paginas separadas para cada um dos elementos (Contato, Home, Curricolo, Portifolio) e nelas foram utilizadas a semantica do Html 
- A estilização foi feita em toda feita em um unico arquivo chamado styles.css (css/styles.css), CSS grid foi utilizado na parte do portfolio
- Todas as imagens tem alt para ajudar na acessebilidade e também respeitando os padrões do html
- Animação da aba menu quando está no celular de forma sutil e natural 
- ##### Bônus Realizados
    - Criação de dois modos escuro e claro, por meio de um script em javascript, os dois modos contendo transições suaves para não incomodar os olhos 
    - Animações sutis em todas as paginas e quando passa o mouse em cima de algum link das paginas elas mudam de cor para destacar
    - Media maior de 90 no Lighthouse em acessibilidade e performance

## Dificuldades encontradas
- Como o curso é mais basico, muitas coisas precisei procurar por fora para conseguir fazer algumas coisas que estava pensando 
- No dimencionamento para mobile encontrei alguns bugs que estavam deixando o visual não tão bom, fiquei algum tempo tentando corrigir esse bug
